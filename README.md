# ClaudeCodeTesting
Sandbox for Claude Code

## Contents

- `london-tourist-dashboard.html` – interactive dashboard of London tourist sites.
- `lloyds-risk-code-game.html` – **Code the Slip**, a quiz game for learning Lloyd's risk codes.
  Open the file in a browser. Modes: stamp the code for a risk, pick the risk for a code,
  type the code from memory, or name the replacement for a retired code. It also has a
  searchable code book and can load the official Lloyd's risk code spreadsheet (.xlsx/.csv)
  so you can play with the exact current list.
